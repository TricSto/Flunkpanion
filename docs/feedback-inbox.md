# Feedback-Inbox (bitte nicht mergen!)

Dieser Branch existiert nur, damit der zugehörige Draft-PR dauerhaft
offen bleiben kann. Der Workflow `feedback-issues.yml` kommentiert auf
diesem PR, sobald neues App-Feedback als Issue angelegt wurde – die
abonnierte Claude-Session wird durch den Kommentar sofort geweckt und
setzt das Feedback direkt um (Details: CLAUDE.md, Abschnitt
„App-Feedback“).

**Diesen PR niemals mergen oder schließen** – er ist nur der
Webhook-Kanal der (temporären) Feedback-Pipeline. Wird die Pipeline
abgebaut, können PR und Branch ersatzlos gelöscht werden.
